# 项目

这里用来展示你打包好的项目、源码说明和下载入口。

## 你可以直接放进来的目录

- 项目静态页面目录： [docs/projects/dist](projects/dist)
- 你后面把打包好的 dist 内容放进这个目录即可

## 推荐内容

- 项目名称
- 项目简介
- 技术栈
- 运行方式
- 下载链接
- 相关截图或演示地址

## 你可以这样使用

1. 把你的打包产物复制到 [docs/projects/dist](projects/dist)
2. 访问页面时，使用下面的链接打开：
   - [打开项目页面](projects/dist/index.html)

> 如果你的 dist 包里没有 index.html，请先确认打包产物是否完整。
